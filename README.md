# 生活秩序設計｜2026–2027 課程報名

Python 3.12+ 標準函式庫實作，無外部套件。前台 `/`，需登入後台 `/admin`，SQLite 儲存於 `.data/registrations.sqlite3`（不納入 Git）。

## 啟動

在本目錄執行 `python3 server.py`，預設綁定 `127.0.0.1:8000`。透過安全環境設定提供至少12字元的 `ADMIN_PASSWORD` 才能登入後台；程式無預設密碼。`HOST`、`PORT`、`DATA_DIR` 可覆寫。對外部署應使用 HTTPS 反向代理，設定 `COOKIE_SECURE=1`；反向代理須保留 Host。不可將本開發用 HTTP 伺服器直接暴露於網際網路。

後台先填寫主辦單位全名、個資聯絡信箱及明確的資料／肖像保存期限，確認告知與授權內容符合實際執行方式，再勾選開放報名。不要將密碼寫入原始碼或版本控制。

## 功能

- 民國115年11月起：實戰9梯、初階3梯、台韓進階1梯，合計13梯、142小時。保留原課程價格，不套用未提供的優惠。
- 響應式課程介紹、梯次篩選與報名；臺北日期已過梯次不可報名。
- 必填個資同意、獨立且無預選的肖像同意／不同意、輸入完整姓名電子簽署。每筆保留伺服器時間及當時告知全文。拒絕肖像授權不影響報名。
- 後台登入、名單搜尋、梯次及肖像授權篩選、狀態管理、CSV 匯出與簽署查閱。肖像不同意者標示請避拍。
- 報名為意願登記，未串接付款、通知信或自動錄取。地點、時間、容量、付款、退費規則及正式主辦資料尚待提供。未設定可報名名額，不能視為容量管理系統。

## 驗證

```
python3 -m unittest discover -s tests -v
node --check public/app.js
node --check public/admin.js
```

測試會使用獨立暫存資料庫及測試密碼，不污染正式報名資料。驗證授權、拒絕肖像仍可報名、必要欄位、重複報名、跨站請求、告知版本、狀態與匯出。

## 營運注意

定期使用 SQLite backup API 備份資料庫，備份檔亦含個資，須限制存取與保留期間。簽署欄位為姓名輸入及內容快照，不含憑證式數位簽章或身分核驗。資料到期刪除、當事人權利請求、撤回肖像授權及活動現場避拍，需由主辦單位依告知內容執行；目前沒有自動到期刪除或學員自助撤回功能。匯出資料須另行管控。登入工作階段存在記憶體，8小時到期，重新啟動後須重新登入；單一管理密碼適用小型課務，尚無分角色管理。正式公開前應另進行部署安全及個資告知適用性審閱。

參考網址於建置環境回應代理403，未能檢視其畫面；此版本依提供課程資料獨立設計。
